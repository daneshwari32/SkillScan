# AI Job Skill Scanner

AI based resume scanner - upload resume and get matching jobs.

## Tech Stack
- Python, Django
- HTML, CSS
- Git

## Features
- Upload Resume (PDF)
- Extract Skills Automatically
- Show Matching Jobs

## How to Run
1. git clone https://github.com/daneshwari32/SkillScan
2. pip install -r requirements.txt
3. python manage.py runserver
4. Open http://127.0.0.1:8000
